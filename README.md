# Jukwaa la Taarifa kwa Wanafunzi (Mfano wa Demo)

Landing page ya mfano ya mradi binafsi. **Mradi huu ni wa kujitegemea na hauhusiani rasmi na CAMFED.**
Taarifa zote ni za kubuni (demo). Fomu ya barua pepe haitumi wala kuhifadhi chochote.

## Kuweka kwenye GitHub Pages
1. Tengeneza repository mpya (Public) kwenye GitHub.
2. Pakia faili `index.html` na `README.md`.
3. Settings -> Pages -> Deploy from a branch -> `main` / `(root)` -> Save.
4. Subiri dakika 1-3, kisha fungua kiungo kinachoonekana.
